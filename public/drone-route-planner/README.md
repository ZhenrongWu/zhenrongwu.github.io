# 隨附資料

Demo 模式直接讀這個目錄（Vite 的 `publicDir`），本機全端可以用 `npm run db:seed`（在 `backend/` 執行）寫進資料庫。

> **僅供展示，不可作為實際飛航依據。** 飛行前請以交通部民用航空局「遙控無人機管理資訊系統」與各縣市政府的最新公告為準。

## `no-fly-zones.geojson`：限航區

| 項目 | 內容 |
| --- | --- |
| 資料集 | [臺北飛航情報區限航區範圍圖資](https://data.gov.tw/dataset/49021) |
| 提供機關 | 交通部民用航空局 |
| 授權 | [政府資料開放授權條款第 1 版](https://data.gov.tw/license) |
| 版本 | 107 年 8 月（2018-08-31），開放資料平臺上的最新版本 |
| 取得日期 | 2026-10-28 |
| 原始檔 | 「（總）限航區範圍」KML：`https://www.caa.gov.tw/FileAtt.ashx?lang=1&id=5617` |

轉換：`cd backend && npm run data:convert`（`backend/scripts/convert-caa-kml.ts`）

- KML 中每個 `RCRnn` 資料夾有一條封閉的邊界線，轉成一個 GeoJSON `Polygon`；`-點` 資料夾是頂點標記，略過。
- `id` 為限航區代號（例如 `RCR48`），`properties.name` 為「代號（地名）限航區」，括號改為全形。
- 座標維持原始的 WGS84 經緯度，沒有簡化或重新取點。
- 轉換後的 29 個多邊形都經過 PostGIS `ST_IsValid` 檢查。

依《民用航空法》第 99 條之 13，遙控無人機不得在限航區飛航（經許可者除外），所以系統把限航區當成禁航區檢核。

## `flight-rules.json`：飛行規則

`maxAltitudeM: 121.9`：《民用航空法》第 99 條之 14 第 1 項第 1 款，遙控無人機不得在距地面或水面高度逾 400 呎處飛航。
400 呎等於 121.92 公尺，資料庫欄位只到小數第一位，所以取 121.9 公尺，略為保守。

## 已知限制

- 只有平面範圍：限航區原本有垂直範圍，這裡從地面到無限高都當成禁航（Q-04-1）。
- 沒有收錄「航空站或飛行場四周一定距離範圍」與各縣市公告的禁限航區，例如松山機場周邊在這份資料裡不會被擋（Q-04-2）。
- 法規的 400 呎是距地面或水面，系統的高度是相對起飛點，沒有區分（Q-04-3）。
