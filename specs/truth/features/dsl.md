# DSL：跨領域共用句型

> 測試模式：playwright-bdd，對 `npm run build` 的產物執行；GitHub Pages 以 `e2e/support/github-pages-server.ts` 模擬，專案內部程式不 mock。
> 句型實作：`e2e/steps/*.steps.ts`，共用 fixture 在 `e2e/fixtures.ts`。
> 本檔收錄被兩個以上領域資料夾使用的句型；只被單一領域使用的句型放在該領域的 `dsl.md`。

## 角色

| 角色                     | 說明                                                           |
| ------------------------ | -------------------------------------------------------------- |
| 訪客                     | 用一般瀏覽器、會執行 JavaScript 的使用者                       |
| 不執行 JavaScript 的爬蟲 | 只讀 HTML 的搜尋引擎或 AI 爬蟲，以停用 JavaScript 的瀏覽器模擬 |
| 其他網站                 | 本站以外的網站，例如嵌入本站的頁面或讀取作品資料               |

## Given

| 句型                     | 參數                            | 語意                                                                 | 實作            |
| ------------------------ | ------------------------------- | -------------------------------------------------------------------- | --------------- |
| `訪客開啟 "{網址}" 頁面` | `網址`：站內路徑，例如 `/about` | 以一般瀏覽器開啟頁面，等主內容的標題出現；之後的句型都作用在這個頁面 | `頁面.steps.ts` |

## When

| 句型                      | 參數                       | 語意                             | 實作            |
| ------------------------- | -------------------------- | -------------------------------- | --------------- |
| `他點選導覽列的 "{連結}"` | `連結`：導覽列上的文字     | 點頂端導覽列中名稱完全相同的連結 | `頁面.steps.ts` |
| `他點選 "{文字}"`         | `文字`：按鈕或連結上的文字 | 點畫面上文字完全相同的元素       | `頁面.steps.ts` |

## Then

| 句型                    | 參數               | 語意                           | 實作            |
| ----------------------- | ------------------ | ------------------------------ | --------------- |
| `頁面主標題是 "{文字}"` | `文字`：主標題內容 | 頁面第一個 `h1` 的文字         | `頁面.steps.ts` |
| `畫面顯示 "{文字}"`     | `文字`：部分文字   | 畫面上看得到包含這段文字的元素 | `頁面.steps.ts` |
