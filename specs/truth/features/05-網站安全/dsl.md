# DSL：05-網站安全

共用句型見 [../dsl.md](../dsl.md)。

## Given

| 句型                                   | 參數             | 語意                                                                                  | 實作                |
| -------------------------------------- | ---------------- | ------------------------------------------------------------------------------------- | ------------------- |
| `其他網站以 iframe 嵌入 "{網址}" 頁面` | `網址`：站內路徑 | 在 `127.0.0.1` 啟動另一個來源的網頁，以 iframe 嵌入本站頁面，等 iframe 內的程式執行完 | `防止嵌入.steps.ts` |

## Then

| 句型                             | 參數 | 語意                                      | 實作                |
| -------------------------------- | ---- | ----------------------------------------- | ------------------- |
| `嵌入的畫面沒有顯示任何頁面內容` | 無   | iframe 內的 `#root` 是空的，沒有任何 `h1` | `防止嵌入.steps.ts` |
