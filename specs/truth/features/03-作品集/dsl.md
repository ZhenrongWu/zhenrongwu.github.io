# DSL：03-作品集

共用句型見 [../dsl.md](../dsl.md)。作品資料一律從建置產物 `/projects.json` 讀取，與畫面同一個來源（`src/data/projects.ts`），合約見 [../../contracts/03-作品集.yaml](../../contracts/03-作品集.yaml)。

「最新一件作品」指作品編號最大的那一件。

## When

| 句型                                    | 參數                        | 語意                                       | 實作              |
| --------------------------------------- | --------------------------- | ------------------------------------------ | ----------------- |
| `他點選最新一件作品的卡片`              | 無                          | 用滑鼠點最新一件作品的卡片正面             | `作品集.steps.ts` |
| `他在最新一件作品的卡片上按下 "{按鍵}"` | `按鍵`：Playwright 按鍵名稱 | 把焦點移到最新一件作品的卡片正面後按下按鍵 | `作品集.steps.ts` |
| `他點選卡片背面的 "{文字}"`             | `文字`：按鈕文字            | 點已翻開卡片背面上文字完全相同的按鈕       | `作品集.steps.ts` |
| `他按下 "{按鍵}"`                       | `按鍵`：Playwright 按鍵名稱 | 在目前焦點上按下按鍵                       | `頁面.steps.ts`   |
| `其他網站讀取作品資料`                  | 無                          | 以 HTTP 讀取 `/projects.json`              | `作品集.steps.ts` |

## Then

| 句型                                                           | 參數 | 語意                                                                                  | 實作              |
| -------------------------------------------------------------- | ---- | ------------------------------------------------------------------------------------- | ----------------- |
| `作品卡片依作品資料由新到舊排列`                               | 無   | 卡片數量與作品資料相同，名稱依作品編號由大到小排列                                    | `作品集.steps.ts` |
| `卡片背面顯示該作品的說明、使用技術與完成日期`                 | 無   | 卡片背面可以操作且取得焦點，顯示說明、每個使用技術與「完成日期：…」；正面暫時無法操作 | `作品集.steps.ts` |
| `卡片翻回正面`                                                 | 無   | 卡片正面可以操作且取得焦點，背面暫時無法操作                                          | `作品集.steps.ts` |
| `每件作品都有編號、名稱、分類、說明、使用技術、完成日期與圖片` | 無   | 每筆都有整數編號、非空字串欄位、至少一個使用技術、圖片寬高大於 0                      | `作品集.steps.ts` |
| `每件作品的圖片網址都指向本站且可以開啟`                       | 無   | 圖片網址以 `https://zhenrongwu.github.io/` 開頭，站內同路徑回應 200 且是圖片          | `作品集.steps.ts` |
