# DSL：02-搜尋引擎與社群分享

共用句型見 [../dsl.md](../dsl.md)。

## When

| 句型                                    | 參數                        | 語意                                                                              | 實作                |
| --------------------------------------- | --------------------------- | --------------------------------------------------------------------------------- | ------------------- |
| `不執行 JavaScript 的爬蟲讀取 "{網址}"` | `網址`：站內路徑            | 以停用 JavaScript 的瀏覽器開啟頁面，記下 HTTP 狀態碼；之後的句型都作用在這份 HTML | `搜尋引擎.steps.ts` |
| `爬蟲讀取 "{路徑}" 檔案`                | `路徑`：例如 `/sitemap.xml` | 直接以 HTTP 讀取檔案內容                                                          | `搜尋引擎.steps.ts` |

## Then

| 句型                                                 | 參數                 | 語意                                                                                                            | 實作                |
| ---------------------------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------- |
| `回應狀態碼是 {狀態碼}`                              | `狀態碼`：整數       | 爬蟲讀取頁面時的 HTTP 狀態碼                                                                                    | `搜尋引擎.steps.ts` |
| `網頁標題是 "{標題}"`                                | `標題`               | `<title>` 完全相同                                                                                              | `搜尋引擎.steps.ts` |
| `網頁摘要是 "{摘要}"`                                | `摘要`               | `meta name="description"` 完全相同                                                                              | `搜尋引擎.steps.ts` |
| `正式網址是 "{網址}"`                                | `網址`：完整網址     | `link rel="canonical"` 只有一個且完全相同                                                                       | `搜尋引擎.steps.ts` |
| `網頁只有一個正式網址`                               | 無                   | `link rel="canonical"` 恰好一個，不會因為切換頁面而重複                                                         | `搜尋引擎.steps.ts` |
| `網頁沒有正式網址`                                   | 無                   | 沒有 `link rel="canonical"`                                                                                     | `搜尋引擎.steps.ts` |
| `網頁允許搜尋引擎收錄`                               | 無                   | 所有 `meta name="robots"` 都沒有 `noindex`                                                                      | `搜尋引擎.steps.ts` |
| `網頁要求搜尋引擎不要收錄`                           | 無                   | 有 `meta name="robots"` 帶 `noindex`                                                                            | `搜尋引擎.steps.ts` |
| `sitemap 列出以下網址，且每個網址都有最後更新日期：` | 資料表欄位 `網址`    | sitemap 的 `<loc>` 依序與資料表相同，每筆 `<lastmod>` 是 `YYYY-MM-DD`                                           | `搜尋引擎.steps.ts` |
| `robots.txt 允許所有爬蟲收錄全站`                    | 無                   | 有 `User-agent: *` 與 `Allow: /`，沒有任何非空的 `Disallow`                                                     | `搜尋引擎.steps.ts` |
| `robots.txt 指出 sitemap 位於 "{網址}"`              | `網址`：完整網址     | 有一行 `Sitemap: {網址}`                                                                                        | `搜尋引擎.steps.ts` |
| `分享預覽的標題是 "{標題}"`                          | `標題`               | `og:title` 與 `twitter:title` 都相同                                                                            | `搜尋引擎.steps.ts` |
| `分享預覽的摘要與網頁摘要相同`                       | 無                   | `og:description`、`twitter:description` 與 `meta name="description"` 相同且不為空                               | `搜尋引擎.steps.ts` |
| `分享預覽的網址是 "{網址}"`                          | `網址`：完整網址     | `og:url` 完全相同                                                                                               | `搜尋引擎.steps.ts` |
| `分享預覽以大圖卡片顯示 "{圖片網址}"`                | `圖片網址`：完整網址 | `twitter:card` 是 `summary_large_image`，`og:image` 與 `twitter:image` 都是這個網址，且站內同路徑的圖片可以開啟 | `搜尋引擎.steps.ts` |
