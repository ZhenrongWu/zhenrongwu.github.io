# DSL：04-履歷

共用句型見 [../dsl.md](../dsl.md)。

## Then

| 句型                        | 參數              | 語意                                                       | 實作            |
| --------------------------- | ----------------- | ---------------------------------------------------------- | --------------- |
| `履歷依序列出以下段落：`    | 資料表欄位 `段落` | 履歷各段落標題依序與資料表相同                             | `履歷.steps.ts` |
| `下載的檔案名稱是 "{檔名}"` | `檔名`            | 瀏覽器下載的建議檔名                                       | `履歷.steps.ts` |
| `下載的檔案是 PDF`          | 無                | 下載內容以 `%PDF-` 開頭                                    | `履歷.steps.ts` |
| `畫面有 email 聯絡連結`     | 無                | 畫面上看得到 `mailto:` 連結                                | `履歷.steps.ts` |
| `畫面沒有電話號碼`          | 無                | 沒有 `tel:` 連結，畫面文字也沒有台灣手機或 +886 格式的號碼 | `履歷.steps.ts` |
