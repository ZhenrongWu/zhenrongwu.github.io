# 001-seo-improvements：待裁決問題

以下問題先照「目前採用」的做法實作，對應場景標 `@need-clarification`。裁決後更新場景並移除標籤。

## Q-001-1：結構化資料的 `sameAs` 要不要放「開發者英雄基地」

- 場景：`02-搜尋引擎與社群分享/結構化資料.feature`「首頁描述網站的主人」
- 背景：頁尾有三個連結：開發者英雄基地（devherohub.com）、GitHub、LinkedIn。`sameAs` 是「代表同一個人的其他頁面」，搜尋引擎用它把各處的資料連起來。
- 目前採用：只放 GitHub 與 LinkedIn。devherohub.com 看起來是團隊或品牌網站，不是個人檔案頁。
- 需要裁決：devherohub.com 是否是你個人的頁面？是的話加進 `sameAs`；如果是你經營的組織，可以改用 `worksFor` 或 `founder`。

## Q-001-2：分享預覽圖的版面

- 場景：`02-搜尋引擎與社群分享/社群分享.feature`「分享預覽圖的尺寸與替代文字」
- 背景：舊的預覽圖是 640×512 的個人照，大圖卡片會被裁切。
- 目前採用：1200×630，左邊個人照，右邊是名字、英文名與職稱，背景用網站主色。由 `npm run generate-og-image` 產生。
- 需要裁決：版面與文字是否合適？要換成其他設計，替換 `public/og-image.jpg` 即可（維持 1200×630）。
